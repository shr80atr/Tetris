# بازی تتریس
#وقتی وارد بازی میشوید در صفحه اول دو دکمه فعال و دو دکمه غیرفعال وجود دارد. دکمه new game شما را وارد صفحه بازی میکند و دکمه settings شما را وارد صفحه تنظیمات میکند.
# در تنظیمات شما فقط میتوانید رنگ صفحه را عوض کنید و دوتا رنگ برای صفحه وجود دارد و هر بار که دکمه save را میزنید رنگ صفحه عوض میشود و امتیاز هر سطر هم عدد ثابت 5 است که تغییر نمیکند.
# وقتی وارد صفحه بازی میشوید با زدن دکمه استارت پس از 1 ثانیه بازی شروع میشود و آجرها به پایین صفحه می آیند و شما باید تلاش کنید آجرها رو جوری در صفحه قرار دهید که سطرهای صفحه پر شود و امتیاز بگیرید.
# هر وقت مجموع امتیاز های شما مضربی از 15 شود سرعت بازی افزایش پیدا میکند و بازی سخت تر میشود.
# شما در بازی سه تا جان دارید که بعد از هر بار رسیدن آجر ها به بالای صفحه یکی از جان های شما کم میشود و وقتی هر سه جان شما کم شد پیغام میدهد که شما شکست خوردید.
# حتما با لپتاپ یا کامپیوتر بازی کنید.
